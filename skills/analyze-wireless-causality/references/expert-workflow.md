# Agent执行与商业、学术交付

## 角色

一个主Agent按顺序承担：问题定义→数据语义→统计计算→通信机理解释→独立复核→交付。
技能是可复用程序与边界，Agent决定何时使用及读哪个参考，Python负责数值与图形。
agents/openai.yaml只提供界面元数据，不会自动启动多个Agent或后台服务。

允许并行时按清晰契约委派，只读源数据，分别写运行子目录；
主Agent统一假设、输出版本和检验族。独立复核者只看原始任务/产物，不看预设结论。

| 角色 | 输入 | 输出 | 不能越过 |
|---|---|---|---|
| 数据审计 | 源文件、JSON、参数说明 | 字段口径、缺失/时钟/计数审计 | 不填未知设备/处理 |
| 现象定位 | 规范化数据、问题阈值 | 事件表和对齐图 | 不宣布因果 |
| 机理分析 | 事件、分层证据、领域先验 | 竞争假设及反证路径 | 不编造可观测字段 |
| 因果分析 | 已确认DAG、处理/结果/设计 | identified或not_identified | 不把模型拟合当识别 |
| 质量复核 | 代码、来源、报告 | 失败案例、限制和可复现性 | 不为了漂亮结果改样本 |

## 商业输出

第一页：什么问题、影响范围、哪些已确认、优先验证什么、需要谁提供什么。
每项建议记录预期作用方向/代价/可回滚实验/成功标准；效应未知不虚构ROI。
保留数据脱敏边界、版本、输入哈希、分析配置、软件版本、事件ID及专家复核记录。
运行核心完全本地、无运行时网络请求；默认不会调设备、发消息或修改固件。
生产接入需另行实现权限、调度、监控、数据保留、SLA和访问审计；本技能不是已上线服务。

## 学术输出

明确估计目标、识别假设、采集流程、独立实验单元和排除规则。
展示效应量与区间，不只报告显著性；将探索与预注册确认性实验分开。
评估由合成已知因果、反例压力、真实专家标注和独立外部场景四层构成。
合成验证说明实现正确，不证明真实场景因果识别。
新的论文贡献应是可验证的方法/数据/协议，而不是仅把工具串联称为创新。

## 候选研究评估

| 问题 | 评价指标 | 切分/真值 |
|---|---|---|
| 异常定位 | 事件precision/recall、起点偏差、时长误差 | 专家盲标/独立业务日志 |
| 根因筛选 | Top-k召回、错误断言率、拒答正确性 | 已知干预和负对照 |
| 因果效应 | 估计偏差、区间覆盖率、类型I错误 | 模拟机制与随机实验 |
| 设备比较 | 匹配支持覆盖、排序稳定、置信区间 | 多物理设备与独立会话 |
| Agent表现 | 重复运行一致、证据定位正确、工具错误恢复 | 隐藏场景/新字段任务 |
| 工程代价 | 时间、内存、存储、专家复核耗时 | 固定硬件与输入规模 |

建议比较：人工规则、相关/时滞筛选、约束因果方法、同等工具无技能Agent、完整技能。
消融：移除语义适配、时间/缺失保护、因果门槛、反证路径各自造成的错误。
不得凭本项目一次运行报告上述指标已经达到某标准。
