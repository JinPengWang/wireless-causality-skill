# SLE字段、数据层与本项目事实

## 可信度顺序

保留“用户采集描述”“参数表”“逐文件JSON”“数据实测”四类证据，冲突时并列记录。
本项目用户说明频段固定2.4GHz，不切5.8GHz；CSV缺freq_band，记录为用户给定常量，不能声称实测验证。
场景图有机场、食堂、高铁站以及构造干扰/拉远场景；实际condition有食堂、抽屉、拉远等命名。
Fixed当前condition只含功率/码率，不能强行赋予机场或高铁站地点。

## 本项目核验范围（2026-10-23快照）

3组base.csv合计82,474条；15个condition，22个segment。
Fixed 17,727条、5片段；Normal 9,122条、3片段；Mix 55,625条、14片段。
Fixed长片段约281–304秒，另有约4.4–4.5秒短片段，与“每组四分钟”概述不完全一致，以实测覆盖为准。
Fixed存在44条pwrlev=7，其余大部分6；不能按文件名抹掉实际变化。
Normal未发现tx_flushed>0，不代表所有性能指标恒定，也不能据此证明自适应策略优于固定策略。
Mix最大dt=37.145秒；0间隔与缺报均需单独处理。
部分base.time/chan.time为mm:ss.s短写，完整日期不得用通用to_datetime猜测。

## 字段字典

来源：SLE参数对照表_0813.xlsx / SLE Log Params。
表格行号用于追溯，表中500ms是历史说明/需求上下文；JSON和实测支持当前约100ms上报。

| 字段 | 语义/方向 | 派生与禁区 | 证据 |
|---|---|---|---|
| total_tx_size | 自上次打印以来成功发送总字节 | 8×bytes/(1000×dt) kbps；非端到端应用吞吐量 | 第25行 |
| tx_flushed | 超时后放弃传输的包记录 | 保留计数，再派生>0；不能直接叫音频卡顿概率 | 第33行、实测0–11 |
| tx_ack/tx_total | 源ACK计数与发送统计 | 相同有效记录Σtx_ack/Σtx_total；分母0留空 | 第24/28行、JSON |
| ack_rate | 固件百分数 | 与重传的定义要核对；不要直接推出重传率=1−ACK | 第24行 |
| rssi_avg | 接收信号平均值 | 单位未在文字中明确；0保留并标记疑似哨兵 | 第10行 |
| interf_avg | 全信道平均干扰 | 非外部开关状态，更新可能较慢 | 第12行 |
| weighted_interf_avg | weak干扰信道上的干扰 | 不与RSSI直接拼成已标定SINR | 第13行 |
| pwrlev | 发射功率档位 | 8可能代表2Tx双链路7；不换算dBm | 第11行 |
| bitrate | 日志音频码率档位/推算值 | 档位映射不完整，不等于PHY速率 | 第31行、bitrate-mcs页 |
| cnt_diff_total/cnt_total_nb | counter差累计及计数 | 20ms×total/nb，nb>0；只作传输等待代理 | 第32行 |
| cnt_diff_max | 上次统计以来最大counter差 | 20ms倍数，非端到端音频时延 | 第32行 |
| rx_per | 耳机→手机接收方向错误指标 | 不能替代手机→耳机发送成功率 | 第21行 |
| abnormal/cancel/abort_cnt | 异常/软件取消/硬件取消 | 可能反映其他业务占用天线，需原因码确认 | 第30行 |
| hdl | 片段内链路句柄 | h5/h6不是两台独立设备或独立试验 | base.json |
| sn | 日志序列字段 | 不当物理设备序列号 | base数据结构 |
| dt | 同句柄距上次上报秒数 | 使用真实间隔；首条NaN，0不除 | base.json |

保留原始字段。流水线derived值不能覆盖原值。
有效吞吐量区间默认0.05≤dt≤0.4s；报表明确给出被排除记录与覆盖率。
长缺报后区间内字节统计是否覆盖整个长间隔未核验，因此不以零填充或假设100ms计算。

## 数据分层

- base：原始逐上报、逐链路分析主来源。
- chan：0.1s时间箱，多链路宽表；用于覆盖率和独立核对，不能再加到原始总行数。
- episodes/holes：派生标签；episode_gap_bins=100意味着10秒以内间隙可能合并。
- dynamics.npz：15个历史格、5个未来格；历史含决策格。全部使用observed掩码。
  NPZ窗口存在高度重叠，不能当独立因果样本。当前只审计，不训练模型。

## 时间恢复

完整ISO时间优先；短写时用每链路原始顺序及dt累加建立相对时间。
不声称重建了毫秒精度绝对时间；片段首时刻JSON只到秒不足以校准外部干预。
外部日志分析必须核验共同时钟和偏移后再声明session_clock_alignment_verified。
